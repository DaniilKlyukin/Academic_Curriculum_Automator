# Academic Curriculum Automator (ACA)

## Общие сведения
**Academic Curriculum Automator** — программный комплекс на языке Python, разработанный для автоматизации процессов формирования, модификации, верификации и подготовки учебно-методической документации (рабочих программ дисциплин/практик, оценочных материалов) в форматах Microsoft Word и PDF.

Комплекс позволяет оптимизировать рутинные операции при массовом обновлении учебных планов и сопутствующих документов, обеспечивая корректное применение локальных стандартов оформления.

---

## 🛠 Функциональные возможности

Программа предоставляет 14 модулей обработки, доступных через единую консольную панель управления:

### 1. Комплексные автоматические пайплайны
*   **Комплексный пайплайн подготовки (Режим 1)**: Последовательное выполнение очистки временных файлов, конвертации `.doc` в `.docx`, оптимизации размера архивов документов, актуализации листов согласования, обновления подписей ответственных лиц и стандартизации имен выходных файлов.
*   **Генерация оценочных материалов (Режим 2)**: Анализ структуры учебного плана Excel и автоматическое построение многостраничного документа Word, содержащего матрицу соответствия компетенций, диагностические материалы, шаблоны вариантов диагностических работ и интеграцию тестов из файлов рабочих программ (РПД) или сгенерированных посредством интеграции с Google GenAI (API Gemini).

### 2. Интеграция графических материалов и сканированных страниц
*   **Вставка сканов (Режим 3)**: Инъекция графических листов (например, титульных страниц с подписями/печатями) на конкретные страницы документов Word с автоматическим переводом изображений в плавающий режим ("над текстом").
*   **Объединение изображений (Режим 4)**: Сборка разрозненных графических файлов (`.png`, `.jpg`) в многостраничные PDF-документы.

### 3. Редактирование текстового содержимого и реквизитов
*   **Коррекция зон подписей (Режим 5)**: Гибкий поиск и замена ФИО и должностей (с поддержкой регулярных выражений для инициалов и должностных позиций) исключительно в рамках распознанных областей подписей в тексте и таблицах.
*   **Актуализация листов согласования (Режим 6)**: Автоматизированный поиск таблиц актуализации РПД по ключевым фразам и обновление перечня учебных лет с удалением устаревших записей.

### 4. Стандартизация и переименование файлов
*   **Стандартизация имен DOCX (Режим 7)**: Переименование файлов РПД по шаблону `[Код] РП [Дисциплина] [Направление] [Авторы]` на основе сопоставления названий дисциплин с данными учебного плана.
*   **Переименование сканов (Режим 8)**: Оптическое распознавание символов (OCR) на графических страницах и переименование сканов в соответствии со структурой дисциплин учебного плана.

### 5. Конвертация форматов
*   **Конвертация DOCX/PPTX в PDF (Режим 9)**: Массовый экспорт файлов Word и презентаций PowerPoint в формат PDF с помощью COM-интерфейсов пакета MS Office.
*   **Конвертация DOC в DOCX (Режим 10)**: Автоматическое обновление формата устаревших файлов `.doc` с последующим удалением исходных файлов.

### 6. Извлечение данных и оптимизация размера файлов
*   **Экстракция аннотаций (Режим 11)**: Выделение третьей страницы документов (содержащей аннотацию дисциплины) во внешние PDF-файлы для публикации на сайте образовательной организации.
*   **Очистка медиа-объектов (Режим 12)**: Анализ структуры XML-связей `.docx`-файла, удаление дублирующихся или неиспользуемых графических файлов в архиве документа, сжатие тяжелых сканов.
*   **Удаление временных файлов (Режим 13)**: Рекурсивная очистка папок от графических файлов и PDF-копий.

### 7. Служебные утилиты
*   **Экспорт структуры (Режим 14)**: Генерация иерархического древовидного представления каталогов проекта с возможностью ограничения по глубине вложенности и количеству файлов для анализа в ИИ.

## 📂 Архитектура проекта

Программное решение организовано по модульному принципу:

```text
├── core/
│   └── docx_editor.py        # Редактирование DOCX на низком уровне (вставка графики, плавающие якоря)
├── services/
│   ├── generate_assessment/  # Модули автоматической сборки оценочных материалов (Шаги 1–4)
│   ├── annotation_extractor.py
│   ├── approval_processor.py
│   ├── doc_converter.py
│   ├── file_cleaner.py
│   ├── filename_scans_standardizer.py
│   ├── filename_standardizer.py
│   ├── image_service.py      # Сборка многостраничных PDF из графических файлов
│   ├── media_cleaner.py
│   ├── pdf_generator.py
│   ├── prepare_pipeline.py
│   ├── scan_finder.py        # Поиск сканов на основе коэффициентов нечеткого сравнения строк
│   ├── scan_insertion.py
│   ├── signature_processor.py
│   └── structure_exporter.py
├── main.py                   # Главный пусковой файл консольного меню управления
├── requirements.txt          # Зависимости проекта
└── app_errors.log            # Лог системных ошибок времени выполнения
